## What we build

| Website | Best for |
| --- | --- |
| **Business website** | Shops, clinics, tuition & coaching, salons, gyms, restaurants, cafés |
| **Landing page** | Instagram / Facebook bio-link traffic that needs to convert |
| **Booking / enquiry website** | Appointments and enquiries — services, timings, enquiry form |
| **Catalogue / menu website** | Products or menu with photos and prices, order via WhatsApp |

Every site includes a mobile-first design, fast loading, WhatsApp button, Google Maps, contact / enquiry form, basic SEO, and SSL.

**Not e-commerce checkout, not a live booking calendar, not a mobile app** — orders and bookings come through WhatsApp, so nothing gets lost in DMs.

## How it works

1. **Tell us** — what your business does, what you want on the site
2. **We build** — you get a preview link to review
3. **You approve** — 2 free revision rounds included
4. **Go live** — your site is live, and customers can reach you on WhatsApp

## Our stack

**Frontend:** Astro · React + Vite · Tailwind CSS · TypeScript
**Backend:** Go · PostgreSQL · Redis
**Hosting:** Cloudflare Pages · Cloudflare Tunnel

The platform is a monorepo: a public site, customer account, admin dashboard, customer dashboard, blog, and docs — all in one place.
